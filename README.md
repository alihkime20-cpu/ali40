# مساعد Telegram للتعرّف على قطع غيار السيارات

بوت Python يستقبل صورة لقطعة سيارة عبر Telegram، ويرسلها إلى نموذج رؤية OpenAI مهيّأ في بيئة التشغيل لإرجاع وصف أولي للقطعة والعلامات أو الأرقام الظاهرة وأسئلة المتابعة. لا يحفظ البوت ملف الصورة محليًا أو في Supabase. لا يثبت التحليل وحده رقم القطعة أو توافقها أو سلامتها؛ يجب التحقق من رقم OEM/الكتالوج ومعلومات السيارة قبل الشراء أو التركيب.

## الإعداد

1. أنشئ متغيرات البيئة وفق `.env.example`.
2. `TELEGRAM_BOT_TOKEN` مطلوب لتشغيل البوت.
3. `OPENAI_API_KEY` مطلوب لتفعيل تحليل الصور. يمكن اختيار نموذج الرؤية عبر `CAR_PART_VISION_MODEL`؛ الافتراضي `gpt-4o-mini`.
4. `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` اختياريان. عند ضبطهما يستخدم البوت جدول `public.bot_users` لتسجيل مستخدمي Telegram وميزة الإذاعة الإدارية. إذا لم يُضبطا، يستمر البوت دون تخزين دائم للمستخدمين.
5. احفظ المفاتيح كمتغيرات سرية في الاستضافة، ولا تضعها في Git أو في رسائل المحادثة.

متغيرات تشغيل الصور الإضافية:

- `MAX_IMAGE_SIZE_MB`: الحد الأقصى لحجم الصورة، الافتراضي 8 ميغابايت.
- `IMAGE_ANALYSIS_COOLDOWN_SECONDS`: فترة انتظار المستخدم بين التحليلات، الافتراضي 15 ثانية.

## التشغيل المحلي

```bash
pip install -r requirements.txt
python -m app
```

## الاستضافة

البوت يستخدم Telegram long polling، ونقطة التشغيل هي:

```bash
python -m app
```

للاستضافة على Railway، أضف المتغيرات السرية إلى إعدادات الخدمة ثم أعد النشر. لا يحتاج تحليل الصور إلى ترحيل قاعدة بيانات جديد. احتفظ بالجداول والبيانات الحالية ما لم يتم تحديد نطاق حذفها ومراجعته بشكل منفصل.

## اختبارات الجودة

```bash
pytest -q
```

تُرسل الصورة إلى OpenAI لتحليلها عند طلب المستخدم. وضّح ذلك للمستخدمين، وراجع سياسة الاحتفاظ والخصوصية الخاصة بمزود النموذج قبل تشغيل البوت على نطاق واسع.
