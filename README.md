# كتالوج صور وأسماء قطع غيار السيارات

بوت Telegram خاص بمالكه. لا يحتاج اشتراك قناة، ولا يطلب كتابة الاسم عند البحث. يُنشأ لكل منتج سجل واحد يتكون من **صورة مرجعية واسم تختاره أنت فقط**؛ ثم ترسل صورة المنتج لاحقًا فيعيد الاسم المحفوظ إذا وجد تطابقًا بصريًا واضحًا.

## الاستخدام

- `/start` أو `/help`: تعليمات الاستخدام.
- إضافة منتج: أرسل `/addpart`، ثم صورة مرجعية مع الاسم في تعليقها؛ أو أرسل الصورة أولًا، ثم الاسم فقط عندما يطلبه البوت.
- بعد تسجيل المنتج: أرسل صورة المنتج وحدها ليبحث بين الصور المرجعية ويرد بالاسم المحفوظ فقط عند التطابق الواضح.
- `/catalog`: عرض الأسماء المسجلة.
- `/cancel`: إلغاء إضافة جارية.

لا تُطلب أرقام قطع أو ماركة أو تفاصيل أخرى. عند عدم وضوح الصورة، يصرح البوت بعدم اليقين بدل إرجاع اسم خاطئ. جودة المطابقة تتأثر بتشابه المنتجات وبوضوح الصور، وتزداد مدة وكلفة المقارنة مع كبر عدد الصور المسجلة.

## الخصوصية والتخزين

صور المنتجات المرجعية والأسماء تحفظ في جدول `public.car_parts_catalog` ومخزن Supabase الخاص `car-part-catalog`. صورة البحث لا تُحفظ في الكتالوج. تُرسل صورة البحث وصور المراجع إلى OpenAI للمقارنة. خدمة الكتالوج متاحة فقط للمالك المحدد في `ADMIN_USER_ID`؛ لا تنشر مفتاح الخدمة.

## الإعداد

- `TELEGRAM_BOT_TOKEN`: مطلوب.
- `ADMIN_USER_ID`: معرّف Telegram المسموح له باستخدام البوت.
- `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY`: مطلوبان لحفظ صورة الاسم والمطابقة.
- `OPENAI_API_KEY`: مطلوب للمقارنة البصرية.
- `CAR_PART_VISION_MODEL`: الافتراضي `gpt-4o-mini`.
- `MAX_IMAGE_SIZE_MB`: الافتراضي 8.
- `IMAGE_ANALYSIS_COOLDOWN_SECONDS`: الافتراضي 15.

يتضمن الترحيل `supabase/migrations/20261010034400_create_private_car_parts_catalog.sql` إنشاء جدول مستقل ومخزن صور خاص. لا يمس الجداول التعليمية الأخرى.
