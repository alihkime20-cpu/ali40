# صفحات SABACUN المنفذة

## الهوية والتنقل

أصبح المشروع منصة **SABACUN** العربية للأدوات الرقمية ومركز المعرفة، مع واجهة RTL وتصميم تقني حديث. تم إزالة تجربة الأخبار وRSS ومسارات تفاصيل الأخبار من المنتج النهائي.

## الصفحات العامة

| الصفحة | المسار | الوظيفة |
|---|---|---|
| الصفحة الرئيسية | `/` | تعريف SABACUN، البحث، التصنيفات، الأدوات الشائعة، مركز المعرفة، وشرح المعالجة المحلية |
| جميع الأدوات | `/tools` | استعراض الأدوات حسب التصنيف والبحث الداخلي |
| الأداة المفردة | `/tools/:slug` | تشغيل الأداة، شرح استخدامها، تنزيل النتيجة، وبيان الخصوصية |
| مركز المعرفة | `/knowledge` | مقالات عربية أصلية مرتبطة بالأدوات والاستخدام العملي |
| المقالة المعرفية | `/knowledge/:slug` | قراءة دليل معرفي مستقل مرتبط بأداة أو موضوع تقني |
| من نحن | `/about` | هوية SABACUN وهدف المنصة ومنهجية بناء الأدوات |
| الخصوصية | `/privacy` | البيانات، المعالجة المحلية، ملفات الارتباط، وحقوق المستخدم |
| الشروط | `/terms` | شروط استخدام الأدوات والقيود والمسؤولية |
| سياسة المحتوى | `/content-policy` | معايير المحتوى الأصلي والاستخدام المقبول |
| اتصل بنا | `/contact` | البريد الرسمي وواتساب الأعمال وقنوات التواصل |

## حالات واجهة المستخدم

تتعامل الواجهة مع حالات التحميل والفراغ والخطأ، وتدعم العرض المتجاوب على الهاتف والحاسوب. لا تعتمد الصفحة الرئيسية أو مركز المعرفة على بيانات أخبار أو مزامنة خلفية.
